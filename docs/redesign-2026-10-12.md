# Coin Quest visual redesign — 12 October 2026

## Verdict

**Website: VERIFIED for the local routes and states listed below.**
**Native: PARTIAL — implementation is in place, but the Mac locked during the
final Simulator walkthrough.** The UI tool twice reported that automatic unlock
could not unlock it. The user has been asked to unlock the Mac. Do not call the
remaining native screens verified until that walkthrough is completed.

No commit, push, production deployment, Android run, release build, or production
Admin write was performed. This work sits on the existing uncommitted native
rebuild; the pre-existing deletions and feature work were preserved.

## Direction and ownership

Use light parchment, evergreen and brass with the existing RPG artwork.
Mitr remains the display family, IBM Plex Sans Thai the body family, and Chakra
Petch the statistics family. Native fonts are bundled TTFs.

- `shared/quest-tokens.css`: shared website palette; matching native colors live
  in `mobile/src/auth/ui.tsx`.
- `shared/quest-design.css`: player shell, Home, panels, forms, statistics,
  module layouts, modal treatment and responsive behavior.
- `character/design.css`: portrait-led profile and profile statistics.
- `admin/design.css`: operations shell, navigation, tables, KPI cards and forms.
- `mobile/src/player/ui.tsx`: shared module introductions, rows, cards and stats.
- `mobile/src/character/Home.tsx`: compact character header and four module
  destinations visible in the first iPhone viewport.
- Native Profile, Debt, Treasury, Prices and Split use the updated primitives;
  Treasury's income editor opens on demand and preserves its draft when closed.

The web ledger now places party members beside entry tools on desktop and stacks
them on smaller screens. Price inputs use available width; mobile price and
quantity share a row with a full-width unit selector below. Financial totals,
labels, select values and date fields are centered where appropriate; prose and
freeform inputs stay leading-aligned. Settings shortcuts no longer cover the
web mobile header; settings also remain reachable through the mobile menu.

Financial formulas, identifiers, permissions and Firebase contracts were not
changed by this visual pass. A render-time asset application fixes the missing
Home chest icon. Treasury forecast support labels now state their meaning.
