## ข้อมูลและการใช้งาน

| ข้อมูล | ใช้ทำอะไร |
| --- | --- |
| ชื่อผู้ใช้ ชื่อแสดงผล รหัสบัญชี และตัวละคร | ระบุบัญชี แสดงโปรไฟล์ และเชื่อมข้อมูลของเจ้าของบัญชี |

## Google Sign-in

Google Sign-in ใช้กับการเข้าสู่ Admin Portal ของผู้ดูแลที่ได้รับสิทธิ์
ระบบขอข้อมูลระบุตัวตนพื้นฐาน ได้แก่ข้อมูลบัญชี อีเมล และโปรไฟล์
ผ่าน Firebase Authentication เพื่อยืนยันตัวตนและตรวจสิทธิ์ผู้ดูแล
การเข้าสู่ระบบปัจจุบันไม่ได้ขอสิทธิ์อ่าน Gmail, Google Drive หรือ Calendar

ข้อมูลระบุตัวตนที่ Google ส่งให้จะประมวลผลผ่าน Firebase Authentication
ส่วนระบบ Admin ใช้อีเมลที่ยืนยันแล้วตรวจสิทธิ์การเข้าถึง ผู้ให้บริการเว็บ
ไม่ได้รับรหัสผ่าน Google จากกระบวนการนี้

## การจัดเก็บและบริการที่เกี่ยวข้อง

ระบบใช้ Firebase Authentication และ Firestore สำหรับบัญชีและข้อมูลที่
บันทึกบนคลาวด์ ใช้ Vercel ให้บริการเว็บไซต์และ API และใช้ Cloudinary
ส่งภาพประกอบของเว็บ เบราว์เซอร์เก็บสถานะการเข้าสู่ระบบ การตั้งค่า
และข้อมูลบางส่วนผ่านพื้นที่จัดเก็บในอุปกรณ์เพื่อให้เว็บทำงานต่อเนื่อง

[ต้องยืนยันก่อนเผยแพร่: รายการ analytics/logging ที่เปิดจริง ระยะเก็บข้อมูล
ของบริการเหล่านี้ สถานที่ประมวลผล และการใช้/ส่งต่อข้อมูลนอกเหนือจากโค้ด]

## การมองเห็นข้อมูลร่วมกัน

ข้อมูลบนกระดานร่วมกันและหน้าโปรไฟล์อาจแสดงแก่บุคคลอื่นตามลักษณะของหน้า
สิทธิ์การเข้าถึง และการแชร์ จึงควรตรวจสอบผู้ร่วมกระดานและข้อมูลที่กรอก
ก่อนแชร์ลิงก์ ผู้ดูแลระบบที่ได้รับสิทธิ์สามารถเข้าถึงข้อมูลที่จำเป็นต่อ
การดูแลระบบและช่วยแก้ปัญหาบัญชี
