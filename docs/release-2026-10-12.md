# October 2026 release preflight

User requested documentation/Skill updates, push and deploy after the native
rebuild, visual redesign and shared-backend repairs. This records release scope
and evidence boundaries, not an assertion that a pending deployment succeeded.
The exact commit, CI run, production alias and Rules release are checked and
reported at release closeout.

## Included work

- Rebuilt Expo 57 player app with the existing Firebase project, website fonts,
  all player modules and cross-client storage contracts. Admin stays on web.
- Website/Admin design changes and functional fixes across auth, signup,
  character, invitations, money/history, module reconciliation and deletion.
- Updated atomic access contracts in `firestore.rules`; emulator integration
  tests are required alongside web tests and native contract checks in CI.
- Versioned same-origin artwork: baseline production smoke reproduced Cloudinary
  404s in the chest icon, portraits and dragons. Production now packages the
  checked-in artwork; CDN testing is explicit with `?assets=cloud`.
- Vercel excludes native source, tests, QA artifacts and internal documentation.
- Installed Coin Quest native-parity, admin-ops and ledger-logic skills updated
  to the actual Simulator workflow and shared data invariants; all three pass
  the skill validator. Installed skills live outside this repository.

## Evidence and boundaries

- Final local release checks: syntax/assets passed, **55 unit tests**, **83
  browser tests passed / 7 intentional skips**, **21 Firebase emulator tests**,
  **58 native contract tests**, native TypeScript and ESLint passed.
- Earlier real Simulator/live-test-account round trips:
  [player worklist](mobile-completion-worklist.md).
- Later backend repairs and emulator evidence:
  [backend audit](backend-audit-2026-10-12.md).
- Simulator remains inaccessible at release preflight because the Mac is locked.
  Earlier per-flow proof does not validate every subsequent native edit. This
  deployment publishes web/APIs/Rules; it does not distribute a native binary.
- No live password reset, account deletion, production data migration or new
  test-account provisioning is required by the non-mutating production smoke.
- Legacy board ACL policy and already-stored public recovery hashes remain
  migration work. Debt histories that cannot be reconciled fail explicitly.
- Firestore billing is disabled; automatic TTL cleanup is deferred without a
  billing upgrade. Rate-limit windows still expire in application logic.

Historical QA documents describe what was deployed or local **at their capture
time**. Later release status is established by exact-SHA CI and live verification,
not by rewriting historical screenshots or calling emulator tests native proof.

## Commands and release order

See [Testing Matrix](../TESTING_MATRIX.md) and
[Deployment Runbook](../DEPLOYMENT_AND_ROLLBACK_RUNBOOK.md). Run web, backend and
native source/contract checks; push `main`; let the single CI deployment finish;
deploy the matching Firebase Rules; verify active Rules contents, API readiness,
unauthenticated access boundaries, production artwork and desktop/mobile routes.
