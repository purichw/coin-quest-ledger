1. ข้อมูลที่ใช้และวัตถุประสงค์

  • บัญชีและตัวละคร: ชื่อผู้ใช้ รหัสบัญชี ชื่อที่แสดง ตัวละคร และความคืบหน้า ใช้ระบุบัญชี เชื่อมข้อมูลข้ามอุปกรณ์ และแสดงโปรไฟล์ ไม่จำเป็นต้องใช้ชื่อจริง แต่ข้อมูลที่เชื่อมถึงบัญชียังคงเป็นข้อมูลเกี่ยวกับผู้ใช้
  • ข้อมูลที่คุณบันทึก: รายรับรายจ่าย หนี้ การชำระ เป้าหมาย ราคา ชื่อสมาชิก และข้อมูลบอร์ด ใช้แสดงรายการ คำนวณยอด และทำงานร่วมกับสมาชิกที่เกี่ยวข้อง
  • การยืนยันตัวตนและกู้คืน: Firebase Authentication ประมวลผลข้อมูลเข้าสู่ระบบ ส่วนระบบเก็บข้อมูลที่จำเป็นต่อการกู้คืนและป้องกันการเข้าถึงโดยไม่ได้รับอนุญาต
  • ข้อมูลทางเทคนิค: ผู้ให้บริการโครงสร้างพื้นฐานอาจประมวลผล IP อุปกรณ์ เบราว์เซอร์ เวลาและข้อผิดพลาดของคำขอ เพื่อให้บริการและรักษาความปลอดภัย ระบบมีบันทึกการดำเนินงานของผู้ดูแลเพื่อการตรวจสอบ

กรอกเฉพาะข้อมูลที่จำเป็น และหลีกเลี่ยงเลขบัตรประชาชน ข้อมูลสุขภาพ เลขบัตรชำระเงิน หรือข้อมูลส่วนตัวของผู้อื่นที่ไม่จำเป็นต่อรายการ

2. Google Sign-in

Admin Portal ใช้ Google Sign-in ผ่าน Firebase เพื่อยืนยันตัวตนและตรวจสิทธิ์ผู้ดูแล ระบบได้รับตัวระบุบัญชี อีเมล และข้อมูลโปรไฟล์พื้นฐานที่ Google ส่งกลับ เช่น ชื่อหรือรูปโปรไฟล์ โดยไม่ได้รับรหัสผ่าน Google

เราใช้ข้อมูล Google เพื่อการเข้าสู่ระบบ ตรวจสิทธิ์ และความปลอดภัยของบัญชีเท่านั้น ไม่ขออ่าน Gmail, Google Drive หรือปฏิทิน ไม่ขายข้อมูล Google ไม่ใช้เพื่อโฆษณา และไม่ใช้ฝึกโมเดล AI การใช้และส่งต่อข้อมูลที่ได้รับจาก Google APIs เป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use

3. ใครเข้าถึงข้อมูลได้

ข้อมูลในบอร์ดร่วมกันอาจแสดงต่อสมาชิก ผู้ดูแลบอร์ด หรือผู้เปิดลิงก์ตามรูปแบบการแชร์และสิทธิ์ของบอร์ดนั้น ข้อมูลโปรไฟล์หรือตัวละครที่เผยแพร่ก็อาจมองเห็นได้โดยผู้อื่น โปรดตรวจสิทธิ์และลิงก์ก่อนแชร์

ผู้ดูแลระบบที่ได้รับสิทธิ์อาจเข้าถึงข้อมูลเพื่อสนับสนุนผู้ใช้ จัดการบัญชี แก้ไขปัญหา และรักษาความปลอดภัย การซ่อนยอดเงินบนหน้าจอเป็นเพียงการซ่อนการแสดงผล ไม่ได้เปลี่ยนสิทธิ์เข้าถึงข้อมูล

เราใช้ Firebase/Google Cloud สำหรับบัญชีและฐานข้อมูล และ Vercel สำหรับเว็บไซต์และบริการฝั่งเซิร์ฟเวอร์ หน้าเว็บโหลดฟอนต์จาก Google Fonts และอาจใช้ Cloudinary สำหรับสื่อของเว็บไซต์ ผู้ให้บริการเหล่านี้อาจประมวลผลข้อมูลในต่างประเทศตามโครงสร้างพื้นฐานและนโยบายของตน ดู ข้อมูลความเป็นส่วนตัวของ Firebase และ นโยบายของ Vercel

เราไม่ขายข้อมูลผู้ใช้ การเปิดเผยอื่นจำกัดตามความจำเป็นในการให้บริการ ป้องกันการใช้ในทางที่ผิด หรือปฏิบัติตามกฎหมายที่เกี่ยวข้อง

4. ข้อมูลในเบราว์เซอร์

เว็บและบริการเข้าสู่ระบบใช้พื้นที่จัดเก็บในเบราว์เซอร์ เช่น localStorage, sessionStorage และกลไกจัดเก็บของ Firebase เพื่อคงสถานะเข้าสู่ระบบ จำภาษาและธีม เก็บแบบร่างหรือสำเนาข้อมูล การล้างข้อมูลเว็บไซต์อาจทำให้ออกจากระบบและสูญเสียข้อมูลที่ยังไม่ซิงก์ แต่ไม่ได้ลบข้อมูลบัญชีบนเซิร์ฟเวอร์โดยอัตโนมัติ

5. การเก็บรักษาและลบข้อมูล

เราเก็บข้อมูลบัญชีและรายการที่บันทึกไว้ขณะบัญชียังใช้งาน เพื่อให้คุณกลับมาใช้งานต่อได้ การปิดใช้งานบัญชีชั่วคราวหรือออกจากระบบไม่ใช่การลบข้อมูล คุณสามารถขอลบบัญชีผ่านช่องทางติดต่อด้านล่าง

เมื่อตรวจสอบคำขอและดำเนินการลบบัญชี ระบบลบข้อมูลยืนยันตัวตน โปรไฟล์ และข้อมูลส่วนตัวในโมดูลที่ผูกกับบัญชี พร้อมจัดการการเชื่อมโยงที่เกี่ยวข้อง บางรายการในบอร์ดที่มีผู้ใช้หลายคนอาจคงอยู่เพื่อรักษาประวัติและยอดของสมาชิกคนอื่น โดยพิจารณาลดข้อมูลที่เชื่อมถึงผู้ขอลบตามความเหมาะสม

บันทึกการลบ ตัวระบุบัญชีเดิม และข้อมูลตรวจสอบบางส่วนอาจคงอยู่เพื่อป้องกันการนำบัญชีเดิมกลับมาใช้ผิดคน ตรวจสอบความปลอดภัย หรือจัดการข้อพิพาท ปัจจุบันยังไม่มีระบบลบประวัติเหล่านี้อัตโนมัติตามระยะเวลาตายตัว ผู้ให้บริการจะพิจารณาความจำเป็นและการลดหรือลบข้อมูลเมื่อได้รับคำขอ บันทึกและข้อมูลสำรองของผู้ให้บริการโครงสร้างพื้นฐานมีวงจรการเก็บรักษาของตน จึงไม่รับรองว่าข้อมูลทุกสำเนาจะหายทันที
